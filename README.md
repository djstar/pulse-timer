# Workout Timer

Stopwatches with laps, Tabata and interval workouts, and countdown timers. Built for iPhone and screen readers.

- **Stopwatch:** run several at once, with laps and splits. The fastest and slowest laps are marked.
- **Tabata & intervals:** set prepare, work, rest, rounds, sets, rest between sets, and cooldown. Work can end on time or when you tap. Spoken cues and 3-2-1 beeps. Back, skip, ±10 s, and a control lock.
- **Timers:** run several countdowns at once, with ±30 s and an overtime count.
- **History**, saved presets, and offline use once added to the Home Screen.

All code is in `web/`, with no build step. Run the tests with `cd web && node --test`.
